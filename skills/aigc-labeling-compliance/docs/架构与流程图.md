# AIGC 内容标识合规 · 架构与流程图

## 本技能的四层结构

```mermaid
flowchart TB
  U["使用层：探店短视频编导 的使用者"]
  T["触发层：AIGC 内容标识合规"]
  X["执行层：5 个步骤"]
  O["产出层：合规检查+标识建议"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 无内容团队的餐饮/美业/健身门店老板（71% 无专业内容团队，据 R4 调研）；员工定位：门店的"编外内容总监"：每天给出拍什么、怎么拍、怎么挂团购的完整答案 |
| 触发层 | 关键词 / 显式点名「AIGC 内容标识合规」；触发方式：用户提出需求 |
| 执行层 | **接收输入**：确认拿到的是「文案」，先做完整性检查。 → **生成内容合规自查与标识提示**：按该定义执行，并把用到的输入项显式写进产出。 → **交叉校验**：把本步结论与上一步结论对一遍，出现矛盾先解决矛盾再往下走。 → **落盘产出**：按「输出契约」四要素定稿，缺数据的写 `<待填>`。 → **回指自检**：逐个数字回指输入来源，回指不上的删掉。 |
| 产出层 | 合规检查+标识建议 |
