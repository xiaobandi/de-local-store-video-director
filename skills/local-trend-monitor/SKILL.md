# 本地热点监控

> **能力**：同城热点与平台话题抓取匹配
> **输入 → 产出**：城市+品类 → 选题清单
> **归属**：探店短视频编导（`de-local-store-video-director`）
> **成熟度**：契约完备（待补真实执行证据）

## 解决什么问题

**做**：选题策划、脚本与口播文案、分镜建议、封面标题、发布排期、团购挂载建议；**不做**：不代发（发布动作留给老板一键完成）、不承诺播放量、不做付费投流建议 这一环里，最容易被跳过、
也最容易出错的就是「本地热点监控」。本技能把它固化成可重复执行的步骤，
避免每次靠临场发挥、结果不可比。

## 输入

- **必需**：城市+品类
- **可选**：口径说明、历史基线、约束条件（预算/时效/合规要求）

若缺少必需输入，**明确告诉用户缺什么，不要猜**。信息不足时的默认行为是提问。

## 环境探测与降级

> 本技能跨平台可用（WorkBuddy / ChatGPT / DeepSeek Harness / Kimi Work / 豆包工作）。
> **不要假设任何平台专有的工具名。**

| 能力 | 首选路径 | 降级路径 |
|---|---|---|
| 读取工作区文件 | 平台原生文件读取 | 请用户直接粘贴内容 |
| 执行代码 | 本技能自带脚本目录 | 按正文规则手工推导，跳过脚本 |
| 生成二进制文件 | 平台文档/图像能力 | 输出 Markdown，注明需自行转换 |
| 联网取数 | 平台检索能力 | 请用户提供截图/导出文件，标注「未实时校验」 |
| 长文分段处理 | 分块处理并汇总 | 提示用户分批投喂 |


## 输出契约

产出 **选题清单**，必须齐备以下四要素：

| 要素 | 要求 |
|---|---|
| 输入来源 | 逐条列出实际用到的输入项与位置 |
| 产出内容 | 选题清单 |
| 依据与结论 | 每条结论对应到输入里的哪一句/哪一个数 |
| 未决 · 待填 | 缺数据的地方写 `<待填>` 并给出获取方式 |

## 数值与事实纪律（硬约束，违反即判失败）

本技能产出的**任何具体数字**，都必须能在输入材料里找到出处。

1. **可溯源**：每个数字都要能指着输入说"这句/这张表里写的"。写不出来源，
   就不要写这个数字。
2. **找不到就留空**：输入里没有的数字，输出 `<待填>`，并单独列出「需要用户补充」
   清单。**禁止**用"约""大约""估计""行业平均""通常"等词把缺失的数字糊过去。
3. **不推算未被授权的比例**：输入给了分子没给分母，就不要输出百分比；
   给了总额没给口径，就不要拆结构。
4. **不虚构外部事实**：不编造竞品数据、平台规则、政策条款、用户案例。
   需要外部事实时，明确写出「需查证：<具体项>」。
5. **单位与口径一致**：金额标注币种，时间标注时区/口径（自然日/工作日），
   比率标注基数。前后不一致时以输入材料为准并标注冲突。
6. **四舍五入要说明**：保留几位、是否四舍五入，在输出里写明。

> 自检口令：**逐数字回指**。产出后按顺序念每一个数字，逐个说出它在输入里的位置；
> 说不出位置的，删掉或改为 `<待填>`。


## 执行步骤

1. **接收输入**：确认拿到的是「城市+品类」，先做完整性检查。
2. **同城热点与平台话题抓取匹配**：按该定义执行，并把用到的输入项显式写进产出。
3. **交叉校验**：把本步结论与上一步结论对一遍，出现矛盾先解决矛盾再往下走。
4. **落盘产出**：按「输出契约」四要素定稿，缺数据的写 `<待填>`。
5. **回指自检**：逐个数字回指输入来源，回指不上的删掉。

## 质量闸门（产出前逐条自检）

- [ ] 输出四要素齐备，没有空标题
- [ ] 每个数字都能回指到输入；回指不上的已删或改为 `<待填>`
- [ ] 「未决 · 待填」清单非空时，已在产物开头提示用户
- [ ] 没有越过下面的「不做」

## 边界

**做**：同城热点与平台话题抓取匹配

**不做**：
- 不代替用户做最终决策，产出定位是「建议 + 依据」
- 不执行任何对外发布动作（发布由人工确认闸门控制）

## 业务红线（10 条，写死在提示词里）

| # | 红线 | 触发时的动作 |
|---|---|---|
| 1 | 不披露成本结构、供应链来源、内部毛利 | 直接拒答并说明原因 |
| 2 | 用户隐私信息必须脱敏，不留手机号/身份证/地址原值 | 脱敏后再输出，并标注已脱敏 |
| 3 | 不贬低竞品、不做未经证实的负面断言 | 改为陈述可核验的事实差异 |
| 4 | 舆情/维权类内容一律升级转人工，不自动对外发声 | 产出「待人工决策」清单 |
| 5 | 安全/健康/功效类表述审慎归因，不做绝对化承诺 | 加限定语或拒答 |
| 6 | 不越权承诺价格、账期、赔偿、时效 | 标注「需授权确认」 |
| 7 | 引用平台规则/政策前先校验时效 | 附发布日期与来源 |
| 8 | 数据先查异常再解读（缺日、重复、跳变） | 输出「数据健康度」说明 |
| 9 | 分类/分层结论必须声明边界与置信度 | 附「本结论适用范围」 |
| 10 | 跨对象数据（其他店铺/账号/客户）一律不得挪用 | 拒绝并提示合规风险 |
