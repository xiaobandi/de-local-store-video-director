# 使用示例

技能：**封面标题**（`wf-local-video-cover-title`）

> ⚠️ **本技能的真实效果示例尚未补齐**：以下仅为输入 / 输出契约（**不构成效果证据**）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

---

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/title_gen.py --topic 'AI 帮做小红书选题' --platform 小红书 --audience '自媒体新手' --n 6
```

**真实输出**：

```console
平台：小红书（标题上限 20 字）
1. AI 帮做小红书选题值不值？   [极简钩子] 14字
2. AI 帮做小红书选题到底值不值？   [疑问钩子] 16字
3. AI 帮做小红书选题亲测   [极简钩子] 12字
4. 为什么你的AI 帮做小红书选题没人看？   [疑问钩子] 19字
5. AI 帮做小红书选题做错了，难怪没效果   [反差冲突] 19字
6. AI 帮做小红书选题避坑   [极简钩子] 12字

以下公式因缺少真实事实被跳过（脚本不会自造数字）：
  - 数字清单：缺 n → --numbers（素材里真实存在的数量，如卖点条数）
  - 结果前置：缺 benefit → --benefits（有出处的效果，如「省下每天2小时」，禁止自造）
  - 时间限定：缺 days/minutes → --days（有出处的上手周期）；--minutes（有出处的学习时长）
```

> 模板引擎产出多个结构互不相同的候选标题，供人工挑选

> **注意**：标题模板产出的是**候选池不是定稿**——必须人工筛掉不合人设的。

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/title_gen.py --topic 'AI 帮做小红书选题' --platform 小红书 --audience '自媒体新手' --n 6
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/title_gen.py --topic 'AI 帮做小红书选题' --platform 小红书 --audience '自媒体新手' --n 6 || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
