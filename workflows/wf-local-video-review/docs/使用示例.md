# 使用示例

技能：**数据复盘**（`wf-local-video-review`）

> ⚠️ **本技能的真实效果示例尚未补齐**：以下仅为输入 / 输出契约（**不构成效果证据**）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

---

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/brief_render.py --kind battle --file examples/input/battle.json --title '双十一预售首日战报'
```

**真实输出**：

```console
# 双十一预售首日战报

> 生成日期：2026-09-30　格式：battle

**战果总览**：双十一预售首日战绩：GMV 8.6 万，超目标 23%

## 渠道拆解

| 指标 | 数值 |
|---|---|
| GMV | 86,000 |
| 目标 | 70,000 |
| 完成率 | 123% |
| ROI | 3.4 |

## 高光内容

- 小红书笔记导流占比 41%，为第一来源

## 失手复盘

- 客服 3 分钟响应率降至 62%

## 下轮调整

- 大促期增派 1 名客服
- 复投表现最好的 3 篇笔记
```

> 战报固定「战果 / 渠道拆解 / 高光 / 失手 / 下轮调整」五段，失手段不可省略

> **注意**：只报战果不报失手的战报**没有决策价值**，模板里已强制保留失手段。

---

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/brief_render.py --kind battle --file /path/to/your-data/battle.json --title '双十一预售首日战报'
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/brief_render.py --kind battle --file examples/input/battle.json --title '双十一预售首日战报' || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
